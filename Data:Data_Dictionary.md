# Data Dictionary: South Korean Presidential Speeches Dataset  
  
This data dictionary describes the columns, data types, units, and examples for the processed corpus of 600 South Korean presidential speeches (1961–1992) used in this computational text analysis.  
  
| Column Name | Type | Units / Format | Example | Description |  
| :--- | :--- | :--- | :--- | :--- |  
| `doc_id` | Integer | ID Number | `43` | A unique identifier assigned to each individual speech in the corpus. |  
| `president` | Categorical | N/A | `Chun Doo-hwan` | The name of the president who delivered the speech (`Park Chung-hee`, `Chun Doo-hwan`, or `Roh Tae-woo`). |  
| `year` | Integer | YYYY (Year) | `1984` | The calendar year in which the speech was officially delivered. |  
| `date` | Date | YYYY-MM-DD | `1984-03-01` | The exact date of the speech delivery (if available in metadata). |  
| `kind` | Categorical | N/A | `기념사` | The official classification/type of the presidential address as categorized by the Presidential Archives. Common values include `기념사` (Commemorative/Anniversary Speech), `성명/담화문` (Official Statement/Declaration), `환영사` (Welcoming Address), and `기타` (Other). |  
| `title` | Text | String | `New Year Policy Statement` | The official title or occasion of the presidential address. |  
| `text` | Text | String (Korean characters) | `국민 여러분...` | The original, unprocessed full text of the speech in Korean. |  
| `text_preprocessed` | Text | String (Tokens) | `국민 정부 나라 경제` | The cleaned text after lowercase transformation, whitespace tokenization, and custom stopword filtering. |  
| `topic_1` | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.045` | The calculated LDA topic probability distribution score for Topic 1. |  
| `topic_2` | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.302` | The LDA topic probability score for Topic 2 (Democratization & Global Vision). |  
| `topic_3’ | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.154` | The LDA topic probability score for Topic 3 (Anti-Communism). |  
| `topic_4` | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.088` | The LDA topic probability score for Topic 4 (National Identity & Patriotism). |  
| `topic_5` | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.210` | The LDA topic probability score for Topic 5 (Economic Industrialization). |  
| `topic_6` | Float / Numeric | Probability Ratio (0.0 - 1.0) | `0.181` | The LDA topic probability score for Topic 6 (Social Movements & Civic Spirit). |  
| `sentiment_score` | Float / Numeric | Sentiment Index / Value | `0.412` | The final aggregated emotional sentiment score calculated using the KNU Sentiment Lexicon mapping. |  
  
---  
  
## Notes on Data Types and Units  
* **Float / Numeric (Probability Ratios):** For all LDA topics (`topic_1_score` through `topic_6_score`), the values represent the continuous probability distribution generated by Orange. The sum of all topic scores for a single speech equals `1.0` (or 100%).  
* **Sentiment Index:** The `sentiment_score` reflects the standardized valence mapping where higher positive values indicate higher positive emotional framing, and lower/negative values indicate negative emotional framing.
